# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js, React, Three.js / WebGL, Tailwind CSS

## Users

Senior Architectural Engineers, BIM Managers, and AEC Automation Developers coordinating complex computational BIM pipelines, geometry conversions, and model validation.

## Product Purpose

The web command center and interactive showcase platform for GOAT BIM Suite, enabling 3D web model visualization, MaxToRevit conversion tracking, automated architectural code/carbon auditing, and design automation management.

## Positioning

The definitive computational BIM and architectural engineering web platform natively bridging deep desktop BIM automation (Revit .NET / 3ds Max) with real-time web visualization and Middle East / GCC regional standards.

## Operating Context

Architectural and engineering consultancy offices, remote BIM coordination meetings, multidisciplinary design reviews, and automated model handover workflows.

## Capabilities and Constraints

- Interactive 3D WebGL / Three.js model exploration with metadata inspection.
- Live synchronization and logs with desktop GOAT BIM Suite and MaxToRevit plugins.
- Full bilingual layout support (English LTR and Arabic RTL).
- High performance under dense architectural meshes and large IFC/BIM datasets.

## Brand Commitments

- **GOAT BIM Suite / MaxToRevit / CAD-AI Brand Identity**: Technical authority in computational BIM, bridging desktop Revit/.NET/3ds Max pipelines to modern web experiences.
- **Dark Luxury Architectural UI**: Obsidian black baseline (`#0B0D10`), warm brushed architectural bronze/champagne accents (`#C5A880`), deep slate containers (`#14171F`), and crisp hairline borders (`#202634`).
- **Precision Swiss / Bauhaus Grid**: Modular architectural drafting rhythm, hairline wireframe dividers, coordinate telemetry HUDs, and zero decorative fluff.
- **Architectural Bilingual Typography**:
  - Arabic Display & Headlines: **Cairo** (sharp, authoritative, architectural geometric structure).
  - Arabic Body & Technical Data: **IBM Plex Sans Arabic** (crystal-clear legibility at small sizes, optimal for BIM property grids and parameter tables).
  - Latin & Cross-Language: **Plus Jakarta Sans** (clean modernist clarity).
  - Code & Coordinate Telemetry: **JetBrains Mono** with monospace tabular figures (`font-variant-numeric: tabular-nums`).

## Evidence on Hand

- 161 specialized AEC, BIM, 3ds Max, and computational automation skills installed in `.agents/skills/`.
- Host application bridges for Autodesk Revit (.NET 8/10), AutoCAD, and 3ds Max.
- Real-world Saudi Building Code (SBC) and Middle Eastern municipal zoning frameworks.

## Product Principles

- **Architectural Data Truth**: Never approximate or hallucinate engineering coordinates, parameters, or metadata.
- **Out-of-Distribution Craft**: Clean typographic hierarchy, restrained contrast, and zero generic AI slop.
- **Performance First**: Instant loading and fluid 60fps 3D viewport interactions even on dense building models.
- **Bilingual Parity**: Seamless, first-class Arabic RTL experience equal to English with proper typography, mirrored geometry, and numerical alignment.

## Accessibility & Inclusion

- WCAG 2.1 AA compliance.
- High contrast architectural data tables and viewport controls.
- Full keyboard navigation and bidirectional layout mirroring (RTL/LTR).
