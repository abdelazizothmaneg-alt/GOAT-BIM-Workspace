الكلام هنا عن **Goose**، وهو **وكيل ذكاء اصطناعي مفتوح المصدر (Open-Source AI Agent)** موجه للمطورين، تم تطويره بواسطة شركة **Block** (الشركة المطورة لـ Square و Cash App ومؤسسها جاك دورسي).

فكرة الأداة باختصار إنه مش مجرد شات عادي، بل **Autonomous Agent** بيشتغل محلياً على جهازك ويقدر ينفذ مهام برمجية، يعدل ملفات، ويرن أوامر في التيرمينال.

---

### أهم مميزات Goose:
1. **مش مرتبط بشركة معينة (Model-Agnostic):** تقدر تربطه بأي نموذج ذكاء اصطناعي يعجبك (OpenAI، Claude، Gemini، أو حتى موديلات مجانية ومحلية عن طريق Ollama).
2. **له نسختين:**
   - **Goose CLI:** للتحكم المباشر من التيرمينال.
   - **Goose Desktop:** تطبيق واجهة رسومية (GUI) لو بتفضل واجهات سطح المكتب.
3. **مبني على بروتوكول MCP (Model Context Protocol):** تقدر تضيف له إضافات (Extensions) عشان يتصل بـ GitHub، قواعد البيانات، ومصادر الأدوات المختلفة.

---

### صفحة الـ Quickstart بتشرح إيه؟
دليل البدء السريع ده بيوضحلك في 4 خطوات إزاي تشغله عندك:

1. **التثبيت (Installation):**
   - تحميل برنامج الديسكتوب أو تثبيت نسخة الـ CLI (على Mac عبر `brew install --cask block-goose`، أو تحميل مباشر لويندوز ولينكس).
2. **الربط بمزود الخدمة (Configuration):**
   - تشغيل أمر `goose configure` واختيار المزود (مثلاً Claude أو OpenAI) وإدخال الـ API Key الخاص بيك.
3. **بدء الجلسة (Start a Session):**
   - كتابة `goose session` في التيرمينال وتبدأ تديله مهام برمجية ينفذها فوراً.
4. **تفعيل الإضافات (Extensions):**
   - تفعيل إضافات MCP المدمجة (زي أدوات التعامل مع الملفات أو الـ Git) عشان توسع صلاحياته وقدراته.
