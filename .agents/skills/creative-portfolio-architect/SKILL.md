# Creative Portfolio Architect (تصميم بورتفوليو المشاريع المعمارية والهندسية)

An architectural portfolio curation and graphic design skill. It structures project showcases using the proven **5-Phase Case Study Storytelling Framework**, balancing high-impact photography with rigorous technical drawings (floor plans, sections, axonometrics), project factsheet parameters (BIM LOD, GFA, Budget), and multi-page print/screen layouts (A4 Landscape / 16:9).

---

## 1. The 5-Phase Project Case Study Narrative

```
┌─────────────────────────────────────────────────────────────┐
│ PHASE 1: THE HERO HOOK & METADATA FACTSHEET                 │
│ - Full-spread Hero Photograph / Exterior Render             │
│ - Project Title, Client, Location, Year, Gross Floor Area   │
│ - Role & Specific Scope (e.g. Lead BIM / Schematic Design)  │
├─────────────────────────────────────────────────────────────┤
│ PHASE 2: CONTEXT, SITE & DESIGN CHALLENGE                   │
│ - Site orientation, environmental constraints, zoning limits│
│ - Concept narrative: How the design solves the brief        │
├─────────────────────────────────────────────────────────────┤
│ PHASE 3: MASSING EVOLUTION & PROCESS                        │
│ - Early conceptual diagrams (Volumetric form finding)       │
│ - Bioclimatic logic (Solar shading, prevailing wind flow)   │
├─────────────────────────────────────────────────────────────┤
│ PHASE 4: TECHNICAL PROOF & DRAWINGS (Architectural Rigor)   │
│ - Scaled Ground / Key Floor Plan with graphic scale bar     │
│ - Detailed Building Cross-Section & Facade Tectonic Detail  │
│ - BIM Coordination Matrix (Clash resolution metrics)       │
├─────────────────────────────────────────────────────────────┤
│ PHASE 5: MATERIAL EXPERIENCE & COMPLETED SPACES             │
│ - Curated gallery of interior / exterior vignettes (6-8 max)│
│ - Focus on materiality, light, shadow, and human scale      │
└─────────────────────────────────────────────────────────────┘
```

## 3. Layout Best Practices (Digital & Print A4 Landscape)
- **Format**: A4 Landscape ($297 \times 210\text{ mm}$) or 16:9 Screen Ratio ($1920 \times 1080\text{ px}$).
- **The 60/40 Ratio**: Dedicate at least $60\%$ of total page area to visual drawings and renders, and no more than $40\%$ to text.
- **Deep Zoom Lightbox**: For web portfolios, floor plans must never be compressed to illegible thumbnails; embed high-resolution SVG or zoomable viewers.
- **Typographic Discipline**: Keep body text between $9 - 11\text{ pt}$ for print and $14 - 16\text{ px}$ for screen.
