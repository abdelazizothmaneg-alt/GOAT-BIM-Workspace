# Rhino.Inside.Revit (RiR) Automation

Engineering guide for running McNeel Rhino and Grasshopper directly inside the Autodesk Revit process memory space.

## 1. Architecture & Execution Context
* **In-Process Integration:** Rhino runs within `Revit.exe` process space. Both `RhinoCommon.dll` and `RevitAPI.dll` are accessible in the same thread.
* **Element Binding:** Rhino.Inside tracks Revit element `Id`s generated by Grasshopper components to update existing geometry instead of duplicating elements on every re-solve.

---

## 2. Geometry Translation Strategies (Rhino $\rightarrow$ Revit)

Choose the appropriate representation based on downstream documentation requirements:

| Geometry Type | Revit Target Element | Best For | Editing in Revit |
| :--- | :--- | :--- | :--- |
| **Planar Polysurfaces** | Native System Families (`Wall`, `Floor`, `Roof`) | Full BIM documentation, schedules, layer structure | Fully editable |
| **Double-Curved Breps** | `DirectShape` (Category assigned) | Complex facades, organic canopies, competition massing | Non-parametric |
| **Parametric Repetitions** | Adaptive Component / Generic Model Family | Facade panelization with shared parameters | Semi-parametric |
| **SubD Freeforms** | `FreeformElement` inside In-Place Family | Sculptural architectural monuments, organic landscape | Cut by sections |

## 3. C# Code Pattern for DirectShape from Rhino Brep

```csharp
using System;
using System.Collections.Generic;
using Autodesk.Revit.DB;
using Rhino.Geometry;
using RhinoInside.Revit.Convert.Geometry;

namespace ORTools.Computational
{
    public static class RhinoRevitBridge
    {
        public static ElementId BakeRhinoBrepToDirectShape(
            Autodesk.Revit.DB.Document revitDoc,
            Rhino.Geometry.Brep rhinoBrep,
            BuiltInCategory category)
        {
            // Convert Rhino Brep to Revit Solid using RhinoInside conversion extension
            Autodesk.Revit.DB.Solid revitSolid = rhinoBrep.ToSolid();
            if (revitSolid == null)
            {
                throw new InvalidOperationException("Failed to convert Rhino Brep to valid Revit Solid.");
            }

            ElementId createdId = ElementId.InvalidElementId;

            using (Transaction tx = new Transaction(revitDoc, "Bake Rhino Brep to DirectShape"))
            {
                tx.Start();

                DirectShape ds = DirectShape.CreateElement(revitDoc, new ElementId(category));
                ds.SetShape(new GeometryObject[] { revitSolid });
                ds.Name = "Rhino_Parametric_Mass";

                tx.Commit();
                createdId = ds.Id;
            }

            return createdId;
        }
    }
}
```

## 4. Headless Grasshopper Execution

Run parametric Grasshopper definitions inside Revit headlessly (ideal for overnight batch panelization):

```python
import clr
clr.AddReference("Grasshopper")
clr.AddReference("RhinoCommon")
clr.AddReference("RhinoInside.Revit")

import Grasshopper
import Rhino
from RhinoInside.Revit import Revit

def run_headless_gh_definition(gh_file_path):
    """Loads and computes a Grasshopper definition headlessly in Revit context."""
    archive = Grasshopper.Kernel.GH_Archive()
    if not archive.ReadFromFile(gh_file_path):
        return False
        
    doc = Grasshopper.Kernel.GH_Document()
    archive.ExtractObject(doc, "Definition")
    
    # Compute solution
    doc.NewSolution(True)
    return True
```
